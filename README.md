# Стрелковый клуб

Браузерная дуэльная игра для двух игроков. Первый прототип проверяет базовую механику боя: выбор направления выстрела, уклонение, здоровье, журнал раундов и особое правило дробовика.

## Как открыть

Открой файл `index.html` в браузере.

## Что уже есть

- Два игрока на одном экране.
- Выбор оружия для каждого игрока.
- Выбор сектора выстрела: влево, центр, вправо.
- Выбор сектора уклонения: влево, центр, вправо.
- Расчет урона после каждого раунда.
- Таймер раунда на 20 секунд.
- Журнал боя с описанием действий.
- Особое правило дробовика: соседний сектор получает небольшой урон.
- Простая анимация выстрелов, уклонения и урона.
